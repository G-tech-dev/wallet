# Wallet — migrated to Rwanda-Stock

The old Wallet AI assistant has been retired. Its AI/OpenRouter analysis backend is no longer the active project.

The replacement project is the **Roulette Even/Odd Tracker**, a local-first Microsoft Edge Manifest V3 extension that records roulette outcomes and displays historical frequencies. It does not use AI and does not claim to predict the next spin.

**Use the active project:** https://github.com/G-tech-dev/Rwanda-Stock

To install: download the Rwanda-Stock repository ZIP, extract it, open `edge://extensions`, enable Developer mode, choose **Load unpacked**, and select the `extension` folder in the extracted repository.

Roulette outcomes are independent. Historical percentages and streaks do not guarantee or reliably predict future results.
